# ADR 0055 — G10 readiness: direct providers, today's OpenRouter catalog, the model services screen, spend history and the worker container

Status: adopted 2026-11-15 for master plan step G10. Amends [ADR 0052](0052-ai-player-model-access.md) (endpoint formats, OpenRouter price rules) and extends [ADR 0054](0054-ai-player-worker-and-agents.md) (worker packaging, the brain's handling of text-written calls).

## Context

Preparing the paid-model runs and the VPS deployment turned up five gaps:

1. **No OpenRouter model was eligible.** The live catalog (checked 2026-11-15) no longer lists `request` or `image` prices when they are zero. The adapter read the missing fields as unknown prices, so all 283 tool-capable models were refused. It also refused `input_cache_write_1h` and `input_audio_cache`, which apply only to features CraftLayer never uses.
2. **Direct providers were missing.** The owner wanted Anthropic, OpenAI and Google directly as well as through gateways.
3. **The owner had no screen for model services.** Connecting a service, refreshing its models, allowing paid models and raising the hourly budgets were API-only. The default hourly budget (10 calls, $0) also blocks any real AI player session.
4. **The worker could not be built as an image.** The image build never copied the `ai-player` and `ai-players` package manifests before `pnpm install`, so building the current HEAD would fail, and there was no worker image target.
5. **A small model wrote a tool call as text.** In the in-game test, gemma4 answered "say hello" with the text `say(text="Hi OwnerTester! 👋")`, and the player chatted that literally. In another run it answered with a JSON object, `{"tool_name": "look_around", "tool_args": {}}`.
6. **Model calls over HTTP were cut after 5 seconds.** The API sets `connectionTimeout: 5000`, so Node destroys any socket idle for 5 s. A worker's `think` request waits silently for the model, so every call slower than 5 s failed with `fetch failed` (`UND_ERR_SOCKET`; reproduced with the same Fastify settings). The player gave up after three in a row. The e2e test had hidden it because local calls are usually fast; paid models over the internet would have failed most of the time.

## Decision

1. **OpenRouter prices.** A missing `request` field means no per-request fee. `image` is always 0 because CraftLayer never sends images. A listed request fee is still charged. `input_cache_write_1h` and `input_audio_cache` join the fields counted as zero. Tiered `overrides` (a higher price above some prompt size) stay unknown, so those models remain ineligible; honouring them would need a price per request size. Today that excludes, for example, Claude Haiku 5.5 and GPT-6 Luna on OpenRouter.
2. **Endpoint formats.** An operator-declared compatible endpoint gains `api`: `openai_chat` (default) or `anthropic_messages`, and `flavor` gains `openai`, `anthropic` and `google_gemini`. OpenAI and Gemini use their OpenAI-format chat endpoints. Anthropic uses its Messages API: the system prompt is sent separately, turns from the same role are joined, the conversation starts with the user, tools go as `input_schema`, the header is `x-api-key`, and the wire adds the fixed `anthropic-version` header. JSON mode is refused for Anthropic. As before, the operator declares every model with all nine prices, a source and a date. Nothing is discovered.
3. **Model services screen.** On the AI players screen, adults can connect an operator-approved service by pasting its key, refresh its models, and turn a service off or on. They can allow paid models up to a family-wide amount per hour, capped by the instance, or go back to free models only. Allowing paid models writes the organization policy (`free_only: false`, `allow_hosted: true`, cap) and raises the organization, adult and project hourly budgets to at least 600 calls, 6M input and 300k output tokens, 2 concurrent calls, and the chosen money cap. Existing higher values are never lowered. A new read-only route, `GET /api/v1/provider-endpoints` (`provider:manage`), lists the approved services by label, flavor and model count, plus the instance's paid switch. It never returns URLs, addresses or prices. Each AI player's own daily and total limits still apply first.
4. **Spending history.** `GET /api/v1/ai-players/:id/spend-history?days=1..366` (`ai_player:manage`) returns the daily rows, oldest first, for the service clock's UTC days. The Spending tab shows 30 days as bars against the daily limit, a day-by-day table and a CSV download built in the browser.
5. **Worker container.** The image build copies the two manifests, and a new `ai-player` target runs `dist/main.js` as a non-root user. `infra/compose/ai-player.yml` runs it read-only with all capabilities dropped. It sits on the internal network (API) and on its own egress network (the host's published game port through `host.docker.internal`, and Microsoft sign-in). It is **not** on the game-control network, so it cannot reach RCON. The token directory is mounted read-only; the state directory holds the Microsoft sign-in cache.
6. **Text-written calls.** If a reply contains no tool call and the whole text is one call to a known skill, the brain runs it as that call, with the usual argument check. Two shapes are accepted: `name(key="value", …)` (keyword pairs, a JSON object or nothing in the brackets), and a JSON object with `tool_name`/`name`/`tool`/`function` plus `tool_args`/`arguments`/`args`/`parameters`/`input`. Text that starts like a call, or a JSON object naming a known skill, is never said in the game or posted as a reply.
7. **Socket time for model calls.** Only the worker's `think` route raises its socket timeout to 75 s, longer than the gateway's 45 s model timeout and the worker's 70 s wait. It puts the server's value back when the response is sent. Every other route keeps the 5 s idle cut.

## Consequences

- A paid call still needs the instance's `allow_paid` and cap, the organization policy and the hourly budgets. The screen sets the last two, and the operator sets the first in the protected file.
- The zero rules depend on OpenRouter's catalog meaning what it says. A fee OpenRouter charges without listing it would not be counted. The reconciled spend in the ledger would show it, as for any provider.
- Anthropic's newer models reach AI players directly or through Kong, not through OpenRouter, until tiered prices are modelled.
- Parsing text-written calls cannot widen authority: the call still has to name an offered skill and pass that skill's schema.
